## ✨ Features

- **Golden Celestial & Stained Glass Aesthetic:** Deep cosmic obsidian background, warm amber and crystal glows, custom SVG stained-glass arch and halo.
- **Interactive Stardust Canvas:** Real-time particle physics reacting to cursor movement with mouse repulsion and twinkling stars.
- **3D Card Perspective Tilt:** Dynamic card rotation following the cursor on hover.
- **Bilingual Support (RU / EN):** Seamless language switching with local storage memory.
- **Project Showcase & Filtering:** Interactive tabs for Game Modding, Discord Automation, and CC:Tweaked Virtual Systems.
- **Quick Action Cards:** 1-click Discord tag copying with floating toast notification, direct GitHub & Telegram shortcuts.
- **Pure Web Performance:** Built with vanilla HTML5, CSS3, and JavaScript — zero frameworks, zero build steps, blazingly fast load times (<150ms).
